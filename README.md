# Master Sound FX: versões

Instaladores do **Master Sound FX**, que organiza sozinho as músicas e os efeitos sonoros que você baixa, prontos para o Final Cut Pro.

- **Instalar:** baixe o `.dmg` da versão mais nova em [Releases](https://github.com/Final-Cut-Apps/mastersoundfx-releases/releases) e siga o "Como instalar.txt".
- **Atualizar:** o Master Sound FX se atualiza sozinho.

Requer Mac com Apple Silicon e macOS 26 ou mais novo. O código do app não fica aqui.
